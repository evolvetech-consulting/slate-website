Slate for Gmail — Extension Privacy Policy

Last updated: 15 September 2026

This policy covers the Slate for Gmail browser extension specifically — a small, separate piece of software from the Slate desktop app. It is not the same document as Slate’s main privacy policy, which covers the desktop and phone apps and their use of the Gmail API; the extension does not use the Gmail API at all, so a shorter, different policy applies here.

What the extension is for

The extension lets someone who already uses Slate on their computer process a single email they have open in Gmail, without switching windows. It requires Slate to be installed and running on the same computer — it does nothing on its own.

What it reads

When you click the extension’s icon, a small script running on the Gmail page you already have open looks for the identifier of the email conversation currently on screen — the same kind of identifier that already appears in Gmail’s own web address. It does not read the subject, sender, body or attachments of any email, and it does not read your inbox as a whole. It only runs on mail.google.com, and only acts when you click the icon.

The extension does not sign in to Google, does not request any Gmail API scope, and does not use OAuth. It has no access to your mailbox beyond what is visible in the page you already have open.

Where that identifier goes

It is sent to exactly one place: a small server that Slate runs on your own computer (127.0.0.1, sometimes called “localhost”), reachable only from that same machine — never over the network, never to the internet. Slate then does the actual reading and filing, exactly as if you had clicked “Process” inside the app itself. From there, handling that one email is covered by Slate’s main privacy policy.

The extension itself does not operate any server, does not use analytics or tracking of any kind, and does not send anything to EvolveTech Consulting LLC or to any third party.

What it stores

A single pairing code, generated by Slate and entered once, so the extension can prove to Slate’s local server that the request really comes from this extension. It is stored in your browser’s own extension storage (chrome.storage.sync), which Chrome may sync across your own signed-in browser profiles. It never leaves your control, and removing the extension removes it.

Permissions, and why

  • Read the active tab / run on mail.google.com — to find the identifier described above, only when you click the icon.
  • Talk to 127.0.0.1 — to reach the Slate app running on your own computer. No other address is contacted.
  • Storage — to remember the pairing code, so you do not paste it in again every time.

Children

This extension is a business tool and is not directed at anyone under 18.

Changes

If we change this policy we will update the date at the top of this page.
